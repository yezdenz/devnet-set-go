# Complete the user's exact Word worksheet

Use this guide whenever the user supplies or designates a Word worksheet, activity sheet, or submission template, or requires a Word submission. It governs template preservation, where answers and pictures are inserted, indented and justified prose answers, and the limited black-font rule. Read [Formatting.MD](Formatting.MD), [Screenshot.MD](Screenshot.MD), and [Submission.MD](Submission.MD) alongside it.

## Use the designated file without redesigning it

The exact Word file identified by the user is the required starting document. Do not create a blank replacement, reconstruct the worksheet from extracted text or a PDF, apply a generic report template, or substitute a previous student's submission. A reference example may guide evidence placement only; it is not a replacement for the user's current worksheet.

Confirm the designated file from the user's path, attachment, or explicit selection. If several files could be the submission template, ask which one to use. If the required Word file is unavailable or cannot be edited faithfully, request access to that file and continue independent work. Do not invent a substitute layout while waiting.

Keep the supplied original unchanged. Make a separately named working copy directly from that file and edit the copy in place. Record the source and derivative filenames and, when available, the original checksum in Evidence.MD's private register. A different output filename does not authorize a different document design.

## Make additive edits only

Exception for supplied submission checklists: follow [Checklist.MD](Checklist.MD). Within a checklist, preserve all content and formatting and only check existing completion markers for verified finished tasks. Do not add paragraphs, rows, sections, captions, or evidence there. Place any needed answers or proof in the worksheet's designated areas outside the checklist; keep agent review notes in the private register.

Retain every existing part: titles, headings, questions, numbering, instructions, notes, examples, rubrics, tables, labels, images, logos, headers, footers, references, hidden content, comments, tracked changes, and section structure. Do not remove a part because it appears unnecessary or because its task has been answered.

Add answers in the existing blank answer areas or designated editable form fields without deleting printed questions, prompts, or labels. Add content within an existing table cell without clearing its other contents. If a field contains existing text that would have to be removed, do not silently erase it; establish the intended treatment with the user.

When more room or a new evidence section is needed, add paragraphs, rows, sections, or pages at the appropriate location using the worksheet's existing formatting. Preserve the sequence and content of all original parts. Use a designated proof area first; if none exists, add a clearly labeled evidence section without replacing or moving existing sections. Do not create a new cover page or redesign the report.

Preserve the template's font families, sizes, colors, spacing, margins, page setup, table design, and existing breaks, subject only to the scoped answer indentation/alignment and reflection/essay answer-color rules below. Natural reflow and additional pages caused by the added material are acceptable. Do not shrink or restyle the original worksheet, delete existing breaks, or drop content to force the original page count.

Do not flatten editable Word pages into pictures or run a conversion that discards document parts. If an editing method cannot preserve them, stop the affected edit and explain the limitation. A PDF export, if requested, is an additional derivative; it does not replace the editable Word working copy or the original.

## Indent and justify prose answers

All prose answer paragraphs, including checkpoint, reflection, and essay answers, must have a positive first-line indent and ordinary justified alignment. Reuse the template's existing first-line answer indent when one is specified; otherwise use 0.5 inch (1.27 cm). Keep the selected indent consistent for comparable answer areas. For narrow table cells, use a smaller consistent positive indent if needed to keep the text within the cell.

Set paragraph properties on the answers themselves, including pasted answer paragraphs and prose answers inside cells. Do not insert spaces or tabs to imitate alignment, and do not use distributed alignment that stretches the last line. Add a separate answer paragraph when a question and answer would otherwise share formatting; retain all original question text and its styling.

Do not justify or indent the worksheet's questions, headings, labels, captions, screenshots, code blocks, exact prompt quotations, or non-prose form fields under this rule. Preserve their original or required formatting. Check the final layout for excessive spacing, clipped lines, and unwanted changes to the surrounding worksheet. This rule changes answer paragraph formatting only; font colors still follow the scoped rule below.

## Black font applies only to reflection and essay answers

Set the answer text for reflection questions and any question requiring an essay or prose essay response explicitly to black, `#000000`. Apply this to the response text only, including added paragraphs, pasted runs, and answer text inside table cells. Do not rely on inherited blue, accent, theme, or automatic font colors for those answers.

Preserve the original colors of the question wording, section titles, worksheet headings, instructions, labels, rubrics, headers, footers, and all other parts of the document. Non-reflection, non-essay fields follow their local template formatting. New evidence headings, captions, and labels should match the corresponding worksheet style; they are not covered by a blanket black-font override.

Do not recolor the entire document, modify a shared style in a way that recolors other sections, or normalize all headings to black. Keep hidden content hidden and unchanged. Keep genuine screenshot pixels and logo colors unchanged; the font rule is not permission to alter evidence images.

Apply the one-to-two-sentence answer rule from Formatting.MD to reflection and essay question responses as well. If an explicit assignment length requirement conflicts, resolve it with the user rather than silently expanding or shortening the required response.

## Embed required picture proof inside the worksheet

When the task requires pictures in the Word submission, insert the actual image into the working document beneath the relevant question, step, record, or existing proof label. A chat image, external link, filename, standalone attachment, or empty picture placeholder does not satisfy an in-document picture requirement.

Follow a user-designated proofing example by preserving the current worksheet and placing labeled proof images in its appropriate evidence areas. Reuse the worksheet's existing proof layout where one is present. Add only the needed evidence section where it has none; do not copy another submission's personal details, answers, screenshots, or unrelated design into the current file.

Use authentic, requirement-specific screenshots under Screenshot.MD. Keep their aspect ratio, readability, and the user's consistent scale. Include a brief factual caption or note when required, retaining the local worksheet style. Each image must support the associated requirement and required application; an AI-chat image cannot replace execution proof.

Embed the image data so the picture remains visible when the Word file is opened without access to the agent's folders. Keep the raw capture separately where required. Verify any authorized redacted derivative and inspect embedded images for secrets; never fabricate a result or overwrite the original capture.

If required evidence is missing, leave that requirement pending and explain the exact capture needed. Do not insert a fabricated screenshot or mark the document ready while a required proof area is empty.

## Check preservation and the final Word file

Compare the completed working copy with its source before delivery. Confirm every original part remains present and in order, existing images and document objects remain available, worksheet colors outside reflection/essay answer text are unchanged, and only the intended answer/evidence additions and scoped answer indentation, alignment, and color formatting were made. Check hidden content, comments, and tracked changes separately where tools allow; visual similarity alone is insufficient.

Inspect the actual final Word file visually or through a faithful render. Check every page for missing source text, damaged tables, clipped answers, broken image placement, and unreadable proof. Confirm that pictures required inside Word are embedded and appear at their mapped locations. Record those locations in Evidence.MD.

Check that every prose answer paragraph is indented and justified, every reflection or essay answer is black, and other worksheet font colors are retained. Review actual paragraph settings and local formatting or effective styles, including pasted content, rather than assuming a theme or default is correct. Do not change unrelated text to fix an answer's formatting.

Confirm the original remains unchanged. Apply Submission.MD to the final derivative and any requested package. If preservation, color scope, embedded evidence, or visual verification cannot be confirmed, report a partial handoff and the specific unresolved check; do not deliver a self-designed replacement and call it the completed worksheet.
